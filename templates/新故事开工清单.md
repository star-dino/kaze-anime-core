# 新故事开工清单

按顺序勾选。每一阶段结束都要能 `check` 零报错、`snap` 出图。

## A. 前期（导演，不写代码）
- [ ] 一句话 logline：<谁> 在 <哪里> 遇到 <什么>，最后 <怎样>
- [ ] 一段话故事（≤ 150 字）
- [ ] 节拍表 CUES：6–12 个，全部用秒；标出“情绪最高点”
- [ ] 镜头表：每镜 时间 / 场景 / 景别（远/中/近/特写）/ 镜头运动 / 要表达什么
- [ ] 时长与镜头数匹配：平均每镜 2–5 秒（Sunshower 4.2 s，LEVIATHAN 2.1 s）
- [ ] 角色设计：轮廓、配色（3–4 个主色）、尺寸、标志细节、锚点清单
- [ ] 色彩脚本：每个镜头的 `k`、太阳方位；哪里需要主光作弊
- [ ] 美术指导：正向 + 负向 + 情绪（抄 CONTRACT 模板第 1 节的句式）
- [ ] 填好 CONTRACT.md

## B. 骨架（导演）
- [ ] 复制 `src/story/` → `src/story-<名字>/`，改 `src/main.js` 的 import
- [ ] `story.js`：CUES、SHOTS（占位机位）、默认 look、部门清单
- [ ] 每个部门一个空模块：`export function createX(ctx){ return { update(){} }; }`（可从 `templates/story-skeleton/` 复制）
- [ ] `npm run check` 零报错；`snap` 每个镜头一张（可以是空场景）

## C. 环境
- [ ] 天空：积云团块的方位避开主体和特效轨迹
- [ ] 地面/建筑：绘画材质（id 0）；导出 `terrain()` 或落脚点
- [ ] 水面：`look.water`、`waterLevel`；岩石/桩子会自动出接触泡沫
- [ ] 每个镜头的构图用自由机位（`q:test=1&cam=…`）挑过

## D. 角色
- [ ] 零件全部来自 kit 原语；相邻零件不同 id
- [ ] 锚点发布、写进 CONTRACT
- [ ] 表演：先 `onTwos(t)`；原画表 + breakdown；快动作上一拍一
- [ ] 接触：脚落在地面上（terrain / 射线），不漂浮
- [ ] `ctx.shadowRoots.push(root)`；`look.shadow` 框住角色

## E. 特效
- [ ] 每帧 `begin → push → end`；只用 `hash()` 随机
- [ ] 节奏：一拍三（`onThrees`、`drawing(t, 8)`）
- [ ] 水面附近 `mode: 1`；白云/亮天空前的线条 `rim > 0`
- [ ] 涟漪时基 = `onThrees` 的时间

## F. 声音
- [ ] 和声表 + 旋律 + 音效全部引用 CUES
- [ ] 关键冲击前后给音乐 ducking
- [ ] 声像跟随画面（流星从右到左 → pan 从右到左）
- [ ] `npm run audio`；看频谱图核对对位

## G. 审片与交付
- [ ] 全片联系表：每镜首/中/尾
- [ ] `npm run determinism` 通过
- [ ] 性能：GPU 上 scale 2 每帧 < 0.4 s（否则把不在画面的组隐藏）
- [ ] `npm run build`；在浏览器里打开 `dist/*.html` 从头看一遍、听一遍
