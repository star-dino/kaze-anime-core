# 05 特效系统：画出来的水、光、雷

> 对应原作：Sunshower `fx.js`、`fx-core.js`、`fx-rain.js`、`fx-water.js`、`fx-light.js`、`fx-wet.js`、`fx-mat.js`、`fx-overlay.js`；LEVIATHAN `fx-energy*.js`、`fx-splash*.js`、`tether*.js`、`world-ocean-glsl.js`。
> 对应 anime-core：`src/core/fx.js`（GlowBatch / LineBatch / Ripples / boltPts）、`materials.js`（glow/line 材质与遮挡模式）、`src/story/fx.js`。

## 5.1 总原则

1. **无状态**：“Everything is a pure function of time: frames render in random order, so no state may carry from one frame to the next.” 每帧 `begin()` 清空批次 → 按 t 重新 `push` → `end()` 上传。
2. **画出来的，不是模拟出来的**：日本动画的特效是作画（エフェクト作画）—— 硬边、色块、白芯、一拍三。原作没有用任何物理模拟或粒子系统库。
3. **两个场景各司其职**：
   - **主场景（main）**：会遮挡、要描线、要进倒影的“实体”特效 —— 水块、水滴、水帘、水墙。写 `writeOut()`，有自己的 id。
   - **叠加场景（overlay）**：“光”类特效 —— 雨丝、闪光、光束、闪电、十字星。在水面和大气之后画，不进倒影、不被雾冲淡。
4. **水面 pass 的槽位**：涟漪不是网格，而是往水面 pass 写 12 个 uniform 槽（`uRip[i] = (x, z, 起始时间, 振幅)`, `uRipB[i] = (速度, 环宽, 衰减, 泡沫)`），由水面着色器按像素画环。

## 5.2 批次（batch）类：一个 draw call 画几千个

| 批次 | 场景 | 用途 | 关键设计 |
|---|---|---|---|
| `SpriteBatch`（Sunshower） | main | 水滴、溅起的“皇冠”、泡沫、悬挂水滴 | instanced quad，类型在着色器里切换；水滴沿速度方向拉长 |
| `RibbonBatch`（Sunshower） | main | 下落水流的连续“颈部” | 每条丝带 24 段中心线，着色器面向相机，身体会抖动并在下端断成水滴 |
| `GlowBatch` | overlay | 柔光、kira 十字星、光环、爆闪、条纹 | 半径可用“米”也可用“像素” |
| `LineBatch`（LEVIATHAN） | overlay | 闪电、拖尾、等离子丝带 | **顶点着色器按屏幕像素宽度挤出折线**：“so a bolt keeps a crisp drawn weight at any distance” |
| `PuffBatch`（LEVIATHAN） | main | 大水团、水舌、水滴、气泡、碎块 | **写真实深度的冒名顶替者（impostor）**：“they intersect whales, hulls and each other like solid clay, and the engine's ink pass finds their silhouettes” |
| `SheetBatch`（LEVIATHAN） | main | 倾泻的水帘 | 带条纹、撕裂成丝 |
| `DecalBatch` / `MistBatch` | overlay | 海面泡沫贴花 / 软雾团 | 深度软化 |

## 5.3 雨（Sunshower `fx-rain.js`）

- **雨丝在 GPU 上**：三层深度盒子（近 480 条大而少、中 2800、远 3800 细而多），盒子跟着相机走（`uCenter = 相机 + 前向 × dist`），每条雨丝的位置是 `(种子 + 时间) mod 盒子` —— 纯函数、无限循环。
- **逆光闪亮**：一部分雨丝的“头”用加法混合再画一遍（`glit`），太阳在机器人背后，所以雨丝在它身前闪光。
- **伞的遮挡**：当右手是伞时（`shelterAt(t)` 由手腕和指尖锚点算出一个椭圆），着色器把椭圆下方的雨丝裁掉。
- **水面上的雨环**：近处由 CPU 按哈希生成（`cyc = floor((t + o) / 周期)`，用 `weatherAt(t0).rain` 决定这一轮下不下），画成精致的环 + 溅起的小皇冠；远处交给水面 pass 的程序化雨环场。**近 CPU 精画 + 远 GPU 程序化**是一个可以到处复用的分工。

## 5.4 “主角特效”：手上流下的水帘（Sunshower `fx-water.js`）

CONTRACT 把它称为 “the hero FX”：雨水从伞手的指尖边缘流下，形成一串串闪光的水帘。组成：

- 指尖、手掌边缘的锚点 → 每个出水点一条 `RibbonBatch` 水流（连续的颈）+ 下端断开的水滴（`SpriteBatch`，类型 4“悬挂水滴”会在边缘慢慢鼓起再掉落）；
- 手臂出水时整条手臂往下淌水；
- 落点在水面上打出涟漪（写 `uRip` 槽）；
- 一切都由锚点 + 时间算出，导演改了手的姿势，水帘自动跟着走。

材质（`boltMaterial`）：**白芯 + 硬饱和色带 + 可选深色外缘 + 给泛光用的软晕**。

**“打光”回角色身上**：`relightMaterial` 是一个全屏 cel 光照 pass，**乘**到画面上（所以墨线仍是墨线），把闪电的光“画”到其他部门的物体上；`seamMaterial` 让能量沿装甲板之间的缝隙流动（从 data 图里读 id 边界）。

**亮背景上必须有深色边**：“the plate is bright, so every bolt carries a dark rim”（水下镜头）。我在 anime-core 里亲自验证了这一条：白云前的流星拖尾在纯加法混合下**完全看不见**（白 + 光 = 白）。解决：线条材质改成预乘 alpha 混合，芯和色带 alpha=0（纯叠加），外缘 alpha>0（压暗背景并画深色）：

```glsl
// anime-core/src/core/materials.js  lineMaterial
vec3 add = mix(vC.rgb * band, vec3(1.3), core) * vC.a;
float rim = (1.0 - smoothstep(0.88, 1.0, v)) * (1.0 - band) * vRim * clamp(vC.a, 0.0, 1.0);
o = vec4(add + vC.rgb * 0.3 * rim, rim);   // blend: ONE, ONE_MINUS_SRC_ALPHA
```

## 5.6 大水（LEVIATHAN `fx-splash-*.js`）

**冒名顶替水团（PuffBatch）** 是 LEVIATHAN 最聪明的发明之一：

- 每个“水团”是一个面向相机的四边形，片元着色器里画一个**带尖的胶囊/舌头**形状（半径、沿方向的长度、尖端比例、凹凸度），轮廓是一串小圆瓣（“like drawn surf and cumulus”）；
- 它**写入真实深度和描线 id** —— 所以和鲸、船体、彼此之间正确穿插，描线 pass 自动给它勾边；
- **同一团水的所有小团块写同一个“描线深度”**（`inkZ`）→ 描线只画在整团水的外轮廓和大块分界上，不会给每个小泡描一圈；
- 明暗按“整团水”算：在光照反方向的小团画成阴影色（`massTone`）；
- 每张原画（一拍三）轮廓轻微“沸腾”（`boil = mod(uDrawing, 16) * 0.19`）。

**射流（jets）**：一次溅起 = 一圈射流，每条射流是一串沿弹道飞行的水团，头部变细成尖舌；水在 `[0, T]` 时间内持续离开，所以水柱自然拉长、尾部离开海面、最后自己散开。全是闭式解：

```js
const V = Math.sqrt(2 * g * Hj) / Math.max(cp, 0.3);   // 由目标高度反推初速度
const tJ = a - delay;                                   // a = 原画时间 - 出生
// 第 k 个团块：沿射流的位置 = 它离开喷口的时刻对应的弹道点
```

调色板直接用“显示空间”写死四档（高光、受光、阴影、深）：海水白 `#ffffff / #f8fcff / #8fbcf2 / #3f74d6`、海底淤泥、岩石粉尘、海泡沫、水中气泡。

**会站起来的水**（水山、巨浪）：位移网格，用和海洋 pass 同样的五档硬色画（`fx-splash-mesh.js`、`ships-swell.js`）。巨浪镜头 s23 “The film's flat sea is off in this shot”——这个镜头关掉屏幕空间海，换成一整块雕出来的浪面。**按镜头切换实现方式**，而不是追求一个万能系统。

## 5.7 缆绳与细线（LEVIATHAN `tether*.js`）

箭是鱼叉，尾部拖着一根黑色缆绳伸向天空。做法：屏幕空间挤出的折线，`PX = 3.1`（“pen weight in pixels of the 1920 frame”）；**主场景版本写深度和描线 id**，所以会被怪兽、水柱、海水正确遮挡；需要压在光效上的镜头另画一条 overlay 版本。每个镜头手工布一条折线（纯 t 函数）。

## 5.8 千米海洋（LEVIATHAN `world-ocean-glsl.js`）

见 [02 §2.6](02_渲染管线深度解析.md)。补充三个对做大场景特别有用的技巧：

1. **像素足迹 LOD**：每个波段乘 `smoothstep(3, 12, 波长 / 像素足迹)`，小于几个像素的细节自动淡出 → 远处不闪烁。Sunshower 的雨环也是“线宽按像素足迹保证 ≥1 px、太小就退化成闪烁颗粒”。
2. **白浪的生命周期**：每个网格单元一个新月形白浪，`age = fract(t / 周期 + 哈希)`，`grow = smoothstep(0, .22, age) × (1 - smoothstep(.5, 1, age))`，加噪声侵蚀边缘、往上风向撕出泡沫尾 → 像作画的浪花。
3. **巨影**：`uSeaShadow`（位置、朝向、强度）+ `uSeaShadowB`（半长、半宽）—— 一个 uniform 就让 900 m 的黑影在船队下游过。

## 5.9 遮挡模式（我在 anime-core 里补齐的）

overlay 没有深度缓冲，靠 data 图判断遮挡。但**屏幕空间水面不在 data 图里**，水面附近的特效会被水下的海床挡住。anime-core 统一了三种模式（借鉴 LEVIATHAN 的 mode 0/1/2）：

```glsl
bool occluded(float mode, float depth, float bias, vec2 fragXY, vec2 res){
  if(mode > 1.5) return false;                         // 2：不测试
  vec4 sd = texture(uSceneData, fragXY / res);
  bool nearer = sd.b < depth - bias;
  return mode < 0.5 ? nearer : (nearer && sd.a > 0.5); // 0：全测；1：只被赛璐璐（角色）挡
}
```

示例里的入水闪光、闪电、水滴、海面闪点全部用 mode 1：小恐龙站在前面能挡住它们，海床不会。

## 5.10 一个完整的特效镜头怎么写（anime-core 示例）

`src/story/fx.js` 用 120 行实现了“流星入海”：

| 元素 | 写法 | 节奏 |
|---|---|---|
| 流星头 | `GlowBatch` kira 十字星 + 柔光 | 一拍二 |
| 拖尾 | `LineBatch` 两条：暖色宽线带深色外缘 + 冷色细芯；沿线宽度/透明度函数渐细 | 一拍二 |
| 入水闪光 | 柔光（半径随时间扩大、强度指数衰减）+ 光环 + 大号 kira | 一拍三 |
| 闪电 | 6 条 `boltPts`，`seed = drawing(t, 8)*13 + i`，寿命 1.6 s | 一拍三换形 |
| 水滴 | 70 颗，`p = p0 + v·a + ½g·a²`，落回水面以下就不画 | 一拍三 |
| 涟漪 | 3 个 `Ripples` 槽：速度 10 / 5.5 / 2.8 m/s，错开 0.25 s | 水面时基（一拍三） |
| 余晖闪点 | 26 个海面 kira，每张原画重掷“亮不亮” | 8 fps |
| 闪白 | `story.state()` 里 `st.fade = 0.85 → 0`（0.3 s） | — |
| 镜头震动 | `kick(t, CUES.impact, 0.35, 3.0)` | — |

全部读 `CUES.impact`；改一个数字，特效、镜头震动、闪白、音效的低频冲击一起移动。
