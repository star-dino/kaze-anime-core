# 06 程序化音频：连配乐都是代码

> 对应原作：Sunshower `src/audio.js`、`audio-dsp.js`、`audio-music.js`、`audio-sfx.js`、`audio-life.js`、`audio-cam.js`、`audio.html`、`tools/render-audio.mjs`；LEVIATHAN `audio*.js`（加 `audio-inst.js` 管弦乐器、`audio-sfxlib.js` 音效引擎、`audio-master.js` 母带）。
> 对应 anime-core：`src/audio/dsp.js`、`score.js`、`soundtrack.js`、`audio.html`、`tools/render-audio.mjs`。

## 6.1 架构

```
                 ┌ 音乐（audio-music.js）逐采样合成 → dry/send 两条总线
OfflineAudioContext│        → 大厅卷积混响（RT60 2.3 s）→ ducking 增益 → 2:1 胶水压缩 → 通道 0/1
  4 声道离线渲染   │
                 └ 音效（audio-sfx.js + audio-life.js）→ amb / rain / key 三组
                          → 户外卷积混响（短尾 + 对面楼的回声 slap）→ 延迟 6 ms（对齐压缩器前视）→ 通道 2/3
母带（JS）：求和 → 24 Hz 高通 → BS.1770 响度归一到 -16 LUFS（迭代 4 次）→ 前视砖墙限幅 -1.5 dBFS
          → 首尾淡入淡出（最后一个采样精确为 0）→ 16-bit WAV（TPDF 抖动）
```

- **为什么 4 声道离线渲染**：音乐和音效分开测量响度，报告里能看到每秒的分轨响度曲线。
- **为什么全部纯 JS 合成**：“Pure JS so every render is sample-identical (native oscillators drift by ~1e-6 between renders)”。只有卷积混响用原生节点。
- **长度精确等于片长**：`LENGTH = Math.round(DURATION * SR)`，最后 1 秒 cos² 淡出到数字静音。

## 6.2 乐器（全部从零合成）

| 乐器 | 合成方法（Sunshower `audio-music.js`） |
|---|---|
| 钢琴 | 加法合成 40 个分音，带**非谐性系数 B**（`fn = f0·n·√(1+B·n²)`），两段式衰减（快衰 0.26·T60 + 慢衰），双弦失谐拍频，琴槌噪声，制音器释放 |
| 竖琴 / 拨弦 | Karplus–Strong + 全通滤波微调音高，激励噪声先低通（亮度）再去直流 |
| 钢片琴 / 钟琴 / 定音鼓 | 模态合成：`[频率比, 振幅, 衰减]` 一组正弦分音（钟琴 1 : 2.756 : 5.404 : 8.933） |
| 长笛 / 陶笛 | **单音旋律线**一次合成：连音滑音、延迟颤音、气声噪声（带通跟随音高）、吐音“chiff” |
| 弦乐组 / 圆号 | PolyBLEP 带限锯齿波，每个声部自己的失谐和共享颤音 LFO，低通截止随包络打开 |
| 吊镲渐强 | 3 个带通噪声 + 高通，指数上升、峰值后衰减 |

LEVIATHAN 扩展成“交响 + 预告片”编制（`audio-inst.js`）：铜管组（滤波随气息打开、ff 时音色撕裂）、合唱（共振峰库 + 元音插值）、太鼓（音高下滑的鼓皮 + 鼓槌声）、预告片 boom（扫频正弦 + 饱和 + 长次低频尾）、心跳低音、锣（tam-tam）、铁砧、**谢泼德音阶 riser**（无限上升）。

## 6.3 速度图锚定剧情（最值得学的一招）

```js
// Sunshower audio-music.js
export function tempoMap(C) {
  const bt = (C.kfHop - C.kfPreen[0]) / 4;          // 一拍 = 0.65 s（92 BPM）：由“理毛 → 小跳”的间隔决定
  const bc = C.beacons[1] - C.beacons[0];
  const A = [                                         // [第几拍, 必须落在哪个 CUE]
    [0, C.kfPreen[0]], [12, C.kfPreen[0] + 12 * bt], [24, C.roofOver], [36, C.sunBurst], [40, C.rainbowFull],
    [44, C.beacons[0] - bc], [45, C.beacons[0]], [46, C.beacons[1]], [47, C.kfTakeoff], [48, C.kfTakeoff + 0.8],
  ];
  // 拍 → 秒：锚点之间线性插值（局部微调速度）；保证不倒退
}
```

注释原文：“the hop lands on a downbeat, the music stops dead on the drop that hits the bird, the roof settles on a downbeat, the robot's blink is a downbeat, the sun bursts on a downbeat, the rainbow peaks on a downbeat, the two beacon flashes and the take-off are three beats in a row”。

然后**整首曲子用“拍”来写**，和声表是 `[拍, 拍数, 低音, 上方声部]`：

```js
[24, 2, 'F1', ['A3', 'C4', 'F4']],        // shelter: F (the roof settles: home)
[32, 2, 'A1', ['F3', 'C4', 'E4', 'G4']],  // blink:   Fmaj9/A
[35, 1, 'D2', ['G3', 'A3', 'C4', 'D4']],  //          D7sus4 (pivot to G)
[36, 2, 'G1', ['B3', 'D4', 'G4', 'B4']],  // sun!     G  —— 太阳出来的那一刻转到 G 大调
```

导演挪动一个 CUE，速度图跟着伸缩，音乐依然在正确的拍子上 —— **画面和音乐共享同一张节拍表，而不是“对着成片配乐”**。

## 6.4 音效：声像跟着画面走

`tools/render-audio.mjs` 的第一步是**空间探测**：打开影片页，对**每一帧**调用 `FILM.stateFor(f)`，摆好机器人姿态和相机，把 13 个锚点（`perchL, roofR, handR, lightbarL…`）投到相机空间，记录 `pan / dist / height`。音效按这些曲线做声像和距离衰减 —— “so they follow the Director's robot and cameras”。

第二步**画面探测**：读其他部门放在世界里的东西（蜻蜓的关键帧、燕子路径、电线上的乌鸦、水面漂浮物），“so their sounds sit where they are drawn”。音效部门不需要知道这些东西怎么画，只需要读数据。

> 这又一次依赖“纯函数时间”：音频工具可以在不渲染画面的情况下，瞬间拿到任意帧的全部几何状态。

音效清单（Sunshower）：蝉鸣、雨打水面、雨打金属、警笛的一声“啾”、翠鸟的叫声与扑翼、信标、水帘……；`fx.ducks` 返回需要给音乐让路的时段，生成 ducking 曲线（60 ms 起、350 ms 释放）。

LEVIATHAN 的音效引擎（`audio-sfxlib.js`）给出了一组“万能发生器”，值得直接借鉴：

| 发生器 | 能做什么 |
|---|---|
| `tex(o)` | 带 `f(t)/g(t)/pan(t)` 曲线的滤波立体声噪声 —— “wind, sea, roar, whoosh, plasma, steam are all this with different curves” |
| `tone(o)` | 音高轮廓 + 谐波表：呜咽、警笛、多普勒呼啸 |
| `grains(t0,t1,density,ev)` | 随机事件云：雨点、碎石、气泡 |
| `impact` | 次低频下坠 + 主体 + 爆裂 |
| `sonicBoom` | N 波的双响，然后天空在滚动 |
| `thunder` / `crackle` / `arc` | 雷（撕裂 + 不规则滚雷）/ 静电噼啪 / 电弧嗡鸣收尾一声脆响 |
| `friction` | 粘滑摩擦脉冲激励金属模态：弓弦吱嘎、船体呻吟、钢铁尖叫 |
| `whale` | 有粗糙喉音和共振峰的滑音，“谐波随音量增长，所以轻柔的低吟是纯的” |
| `roar` | “a throat the size of a cathedral”：声门脉冲 + 巨大共振峰 + 撕裂噪声 |

LEVIATHAN 母带还加了：**按镜头的水下闷音**（每个镜头一个低通截止频率表，平滑过渡）、胶水压缩、故事重拍上的瞬态提升、tanh 软削波、-14 LUFS、峰值 -1.85 dBFS（保证真峰值 < -1）。

## 6.5 审听：把声音画成图

`render-audio.mjs` 渲染完会：
- 写 cue sheet（每个音乐/音效事件的时间和名字）；
- `ffprobe` 校验时长、`volumedetect` 峰值、`ebur128` 响度；
- 画**带标注的频谱图**：整片 + 8 个局部放大；白线 = 镜头切换，黄线 = CUES，青色短线 = 其他部门的事件（雨滴、乌鸦叫、翅膀下拍）。
- LEVIATHAN 还和参考片做**并排频谱对比 + 响度包络对比**。

AI 没有耳朵，但能“看”频谱图 —— 这是让 AI 自审声音对位的关键工具。我在 anime-core 里用同样方法验证了示例配乐：频谱图上 3.2 s 起的呼啸上扫正好扎进 4.6 s 的入水冲击，冲击后音乐断开 0.35 s，5.6 s / 6.7 s 两次“啵嘤”滑音对准两次起跳（见 [10](10_示例引擎使用说明.md)）。

## 6.6 anime-core 的精简版

| 原作 | anime-core |
|---|---|
| 钢琴、竖琴、长笛、弦乐、圆号、钟琴、钢片琴、定音鼓、镲 | pad（PolyBLEP 三声部）、钢片琴、钟琴（模态） |
| 速度图锚定 CUES | 直接按 CUES 秒数排音符（8 秒短片够用；长片请移植 `tempoMap`） |
| 空间探测、画面探测 | 声像用时间函数手写（`pan: (t) => 0.75 - 1.1 * t/d` 跟随流星） |
| LUFS 归一 + 限幅器 | 峰值归一到 -1.5 dBFS |
| 4 声道分轨 | 2 声道 |

已验证：合成 0.8 s + 离线渲染 1.2 s，输出精确 8.000 s、48 kHz 立体声 WAV。

## 6.7 给新引擎的建议

1. **配乐写在“拍”上，拍锚在 CUES 上**（直接移植 `tempoMap`）。
2. **音效发生器库化**：`tex / tone / grains / impact / ping / pluck / friction` 七个就能覆盖绝大多数需求。
3. **声像从锚点探测**：让工具逐帧采样角色锚点（纯函数时间使之几乎免费）。
4. **母带链固定**：高通 → LUFS 归一 → 限幅 → 淡出，参数写进配置。
5. **出频谱图审听**，标注 CUES 和镜头切换。
